# Portfolio — Hrishita Panda

Personal portfolio website built with React, TanStack Router, and Tailwind CSS.

## 🛠️ Tech Stack
- **Framework**: React 19, TanStack Router
- **Styling**: Tailwind CSS
- **Bundler**: Vite
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run
```bash
npm install --legacy-peer-deps
npm run dev
```

Visit `http://localhost:8080/` in your browser.

## 📂 Project Structure
- `src/routes/` — Application pages (Home, About, Skills, Projects, Creative, Sports, Contact)
- `src/content/portfolio.ts` — Profile content, project highlights, and gallery details
- `src/components/` — Reusable UI and layout components
